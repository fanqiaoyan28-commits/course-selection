# 學生選課申請系統（Course Selection System）

## 專案背景

這是一份網頁設計與程式實作的學習作業，透過製作學生選課申請表，練習 HTML、CSS 和 JavaScript 的基本使用方式。

## 專案目的

本網站以學生填寫選課申請為使用情境，提供一個簡單的表單介面，讓學生輸入基本資料、選擇課程並查看送出後的申請摘要。此專案目前以瀏覽器端的介面與互動練習為主，沒有連接伺服器或資料庫，因此不會保存或實際提交申請資料。

## 功能介紹

- **學生資料填寫**：可輸入姓名、學號、Email 與班級／年級；表單欄位設有必填條件，JavaScript 也會檢查資料是否完整及 Email 格式。
- **課程選擇**：可從程式設計、網頁設計、資料庫管理、資訊管理及商業概論中選擇一門課程。選擇後會顯示對應的簡短課程介紹。
- **老師同意書上傳**：提供檔案選擇欄位，接受 PDF、JPG、JPEG、PNG 格式。不過目前沒有程式讀取、驗證或上傳檔案；送出申請時也不會處理同意書。
- **備註欄位**：提供文字區域供填寫備註。目前送出後不會顯示或保存備註內容。
- **重新填寫**：使用表單重設按鈕可清空表單欄位，並清除送出訊息與結果、重設課程介紹。
- **送出申請**：JavaScript 會阻止表單以一般方式重新載入頁面，檢查必填資料及 Email 格式；通過檢查後，在頁面顯示成功訊息及姓名、學號、課程摘要。這只是前端示範，並未將資料傳送至伺服器或完成真正的申請流程。

## 使用技術

- **HTML**：建立頁面結構、申請表單、輸入欄位、課程選單、訊息區域及操作按鈕。
- **CSS**：設定表單與頁面樣式，包括欄位、按鈕、成功／錯誤訊息、卡片版面及窄螢幕時的排版調整。
- **JavaScript**：更新課程介紹、檢查表單內容與 Email 格式、處理送出和重設事件，並在頁面顯示結果。

## 專案檔案結構

```text
course-selection/
├── index.html   # 網頁內容與選課申請表單
├── style.css    # 頁面外觀與響應式樣式
├── script.js    # 課程介紹、表單檢查及送出／重設互動
└── README.md    # 專案說明文件
```

## 如何執行

1. 將專案下載或複製到電腦中，並確認 `index.html`、`style.css` 與 `script.js` 位於同一個資料夾。
2. 在檔案管理工具中找到專案資料夾。
3. 使用瀏覽器開啟 `index.html`（例如雙擊檔案，或在瀏覽器中選擇開啟檔案）。
4. 在表單中輸入資料、選擇課程，即可查看前端互動效果。

本專案目前不需要安裝額外套件或啟動伺服器。

## 學習心得與未來改進方向

透過這份作業，可以練習如何以 HTML 建立表單、用 CSS 調整版面，再以 JavaScript 回應使用者操作並檢查輸入資料。也能了解不同檔案各自負責的工作，以及它們如何組合成一個可互動的網頁。

後續可以考慮改進以下方向：

- 修正 HTML 標籤拼字，並加強欄位標籤與表單的無障礙支援。
- 依實際需求補上課程名額、選課規則或更完整的欄位驗證。
- 加入同意書檔案的檢查與安全上傳流程。
- 建立伺服器端 API 和資料庫，讓申請資料能經過驗證後保存及查詢。
- 增加送出失敗、處理中等狀態提示，並改善手機與不同瀏覽器上的使用體驗。
